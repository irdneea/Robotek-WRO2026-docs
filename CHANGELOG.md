# Changelog

## v2.0 – 2026-11-24 · Version for the international final
* The real ROS 2 workspace of the car (Obstacle v3 and Open v5, RRC Lite driver, hardware adapters, simulator and evaluation tools) replaces the old wall-following scripts. The Obstacle is the validated version of 12 Nov 2026 (`robotek-learn` commit `8c31eef`).
* Documentation restructured by the five rubric criteria (`docs/01`–`05`), journal, rules compliance, vehicle history.
* README rewritten as an index; MIT licence and credits added; `tools/` added.
* Known limitation: parking in CW is not reliable.

## v1.0 – 2026-11-04 · Repository as submitted before the restructure
* README with team, vehicle versions, wiring and challenge description; first scripts (`src/open`, `src/obstacle`), printed models, photos and videos.
